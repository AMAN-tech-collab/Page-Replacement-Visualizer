# Page Replacement Algorithm Visualizer\n\nA browser-based Operating Systems project using plain HTML, CSS and JavaScript.\n\n## Run\nOpen `index.html` in your browser. No libraries or server required.\n\n## Features\nFIFO, LRU, Optimal, LFU, MFU and Clock; animated step playback; previous/next; frame timeline; fault/hit metrics; comparison; random references; CSV export; responsive UI.\n
